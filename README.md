# nofitsegal.github.io

Personal website of Nofit Segal, served at https://nofitsegal.github.io.

A single static page (`index.html` + `stylesheet.css`), based on [Jon Barron's template](https://github.com/jonbarron/jonbarron.github.io). Images live in `files/`. No build step: edit `index.html` and push. To preview locally, open `index.html` in a browser.
